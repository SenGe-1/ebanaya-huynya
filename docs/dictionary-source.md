# Проверка исходных данных словаря

## `words.txt`

Исходный файл был Dart-фрагментом в Windows-1251 с массивами слов. Для Flutter нужен обычный UTF-8 текстовый ресурс. Текущий `assets/words.txt` содержит 3613 уникальных слов, по одному слову на строку; все проверенные строки состоят из пяти русских букв.

## `Nouns(1).ipynb`

Ноутбук:
1. читает `/content/drive/MyDrive/Birdle/main_1grams.tsv`;
2. очищает частотный список от строк с символами вне русского алфавита;
3. объединяет варианты регистра;
4. использует `pymorphy3` для отбора существительных и приведения к начальной форме;
5. оставляет слова нужной длины и сохраняет `nouns.csv`.

В сохранённом выводе указано 3616 строк на финальном этапе. Сам `main_1grams.tsv` не был предоставлен в репозитории, поэтому полное повторное получение этих 3616 строк из одного ноутбука невозможно без исходного TSV.

## `devcontainer (1)(1).txt`

Это конфигурация среды разработки, а не код игры. Она клонирует Flutter SDK в Codespaces и добавляет его в PATH. Конфигурация сохранена в `.devcontainer/devcontainer.json`.
