# Birdle — игра в слова из пяти букв

Birdle — игра на Flutter для телефона и браузера. Нужно угадать загаданное русское слово за 10 попыток.

## Игровой процесс

- Поле из 10 строк по 5 букв видно сразу.
- Введите слово из пяти русских букв и нажмите стрелку или Enter.
- Зелёный цвет означает, что буква стоит на правильном месте.
- Жёлтый — буква есть в загаданном слове, но в другой позиции.
- Серый — буква не требуется для загаданного слова.
- После 4-й, 6-й и 8-й неудачных попыток открывается дополнительная буква-подсказка.
- Кнопка обновления начинает новую игру.

## Словарь

Игра читает `assets/words.txt`: UTF-8, одно слово из пяти русских букв на строку. В репозитории сейчас 3613 уникальных слов. Исходный пользовательский `words.txt` был в Windows-1251; список преобразован в UTF-8.

В ноутбуке `Nouns(1).ipynb` описан отдельный конвейер обработки частотного словаря НКРЯ. Он ожидает `main_1grams.tsv` в Google Drive и сохраняет результат в `nouns.csv`; в сохранённом выводе ноутбука указано 3616 строк. Сам файл `main_1grams.tsv` в репозитории отсутствует, поэтому этот конвейер не может быть повторён автоматически только из файлов репозитория. Число 3616 в ноутбуке и 3613 в игровом словаре отличается; при необходимости получить точный словарь из ноутбука нужно запустить его с исходным TSV и заменить `assets/words.txt` результатом фильтрации.

## Запуск в GitHub Codespaces

Откройте репозиторий через **Code → Codespaces → Create codespace on main**, затем в терминале выполните:

```bash
flutter pub get
flutter analyze
flutter run -d web-server --web-port 8080 --web-hostname 0.0.0.0
```

Откройте forwarded URL порта 8080.

## Публикация сайта

GitHub Actions собирает веб-версию и публикует её на GitHub Pages при каждом push в `main`.

После успешного workflow откройте:

https://senge-1.github.io/ebanaya-huynya/

Если публикация ещё не запускалась, откройте вкладку **Actions**, дождитесь успешного выполнения **Deploy Flutter web to GitHub Pages**, затем в **Settings → Pages** проверьте, что источником публикации выбран **GitHub Actions**.

## Структура

- `lib/main.dart` — экран и логика игры.
- `assets/words.txt` — словарь игры.
- `pubspec.yaml` — конфигурация Flutter и подключение ресурса.
- `.devcontainer/devcontainer.json` — среда Codespaces на основе исходного файла преподавателя.
- `web/index.html` — HTML-точка входа веб-сборки.
- `.github/workflows/deploy.yml` — автоматическая сборка и публикация GitHub Pages.
