## Если публикация отменена

Если запуск workflow имеет статус `Cancelled`, это означает, что его остановили до завершения; это само по себе не доказывает ошибку в коде. Откройте этот запуск во вкладке **Actions** и выберите **Re-run all jobs**. Дождитесь завершения и проверьте шаг, отмеченный красным крестиком, если сборка завершилась неуспешно.
