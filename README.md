# Birdle — игра в слова из пяти букв

Мобильная игра на Flutter: угадайте загаданное русское слово за шесть попыток.

## Что уже настроено

- Flutter-проект: `pubspec.yaml`
- Игровой экран и виртуальная русская клавиатура: `lib/main.dart`
- Настройки GitHub Codespaces: `.devcontainer/devcontainer.json`
- Каталог ресурсов: `assets/`

## Важно: добавить полный словарь

Файл словаря из исходного `words.txt` преобразован в UTF-8 и содержит 3613 уникальных слов по пять букв. Его нужно загрузить в репозиторий по пути:

```
assets/words.txt
```

Формат: одно слово на строку, UTF-8. Пока файл не загружен, игра использует небольшой встроенный список для проверки интерфейса.

### Как загрузить словарь через GitHub

1. Скачайте подготовленный файл `words_utf8.txt` из текущего чата.
2. Откройте каталог [assets](https://github.com/SenGe-1/ebanaya-huynya/tree/main/assets).
3. Нажмите **Add file → Upload files**.
4. Выберите скачанный файл и укажите имя `words.txt` (или переименуйте файл перед загрузкой).
5. Нажмите **Commit changes** в ветку `main`.

## Запуск

В GitHub Codespaces откройте терминал в репозитории и выполните:

```bash
flutter pub get
flutter run -d web-server --web-port 8080 --web-hostname 0.0.0.0
```

Откройте появившуюся ссылку на порт 8080. Для запуска на подключённом устройстве используйте `flutter run`.

## Правила

- Нужно угадать слово из пяти букв за шесть попыток.
- Зелёный цвет означает, что буква находится на правильной позиции.
- Жёлтый — буква есть в слове, но в другой позиции.
- Серый — буквы нет в загаданном слове.

## Примечание

В словаре могут встречаться редкие слова, имена собственные и ненормативная лексика, поскольку исходный список был сохранён без фильтрации. Если игра предназначена для широкой аудитории, список стоит дополнительно отредактировать.
