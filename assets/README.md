# Словарь игры

Положите сюда файл `words.txt`: по одному русскому слову из 5 букв на строку, кодировка UTF-8.

Полный словарь из предоставленного файла подготовлен отдельно как UTF-8. Загрузите его в этот каталог под именем `words.txt`. После загрузки Flutter возьмёт слова из него автоматически; до этого игра использует небольшой встроенный словарь для проверки интерфейса.
